# 额度伙伴 · GPT应用内版

界面通过MCP Apps在GPT面板内运行，使用官方全局/聊天侧栏入口；不调用独立桌宠程序，不安装Windows启动项，不启动HTTP服务。

## 使用

- 默认只显示人物。右键人物打开设置；点击外侧或Esc收起设置。
- 左键人物或气泡：额度 → 重置次数（按概率显示语录）→ 隐藏；5秒自动收起。
- 三套皮肤及配套气泡主题；呼吸、呆毛、按压、音效；呼吸和呆毛速度均为0.1–6秒。
- 额度每累计下降1个百分点排队冒泡；首次读取、重置和重复值不弹。手动点击取消排队。
- 设置内可编辑语录、查看两档重置时间、隐藏和退出；隐藏或面板不活跃后暂停读取。
- 人物可在面板内拖动、吸附边缘；窗口缩小时自动调整位置和必要的尺寸，人物和气泡保持在可见区域。
- 窗口边框、尺寸和置顶由GPT宿主管理。右键菜单保留置顶状态说明，不伪装成可控制系统窗口。

## 数据和运行方式

本地stdio MCP后端由GPT启动，内附Windows x64 Node运行时，无需安装.NET或单独配置Node。后端只启动Codex的只读用量服务；传输层只允许initialize、initialized、account/rateLimits/read，不调用模型、不启动聊天、不兑换重置额度。

持续接收额度推送，10秒轮询兜底，3秒面板状态同步，文件活动合并刷新。仅监测会话文件的名称/修改信号，不读取聊天内容。多个面板使用活动租约，全部隐藏后释放连接；未正常关闭的面板最多20秒失效。

数据默认在%LOCALAPPDATA%/CodexPetApp。与桌面软件分别保存设置和语录，不读取、控制或启动桌面软件；发布包不包含作者账号、密钥、个人偏好或聊天记录。

## 与独立桌宠的区别

额度、气泡、皮肤、语录、动画与点击顺序保留。拖动边界改为GPT面板可见区域。Windows任务栏避让、独立窗口置顶和开机启动属于桌面窗口行为，不适用于面板内界面；不能把本版描述为逐项保留全部桌面窗口能力。插件面板未挂载时不能保证在GPT其他页面显示提醒。

真实本机只读额度接口、MCP资源与工具、三次点击、单点和多点下降、去重、皮肤主题、0.1–6秒滑块和小窗口适配已验证。UI使用官方MCP Apps SDK和标准AppBridge测试容器验证；测试容器不进入发布包。尚未在当前GPT宿主窗口人工点击验证，本次修复应用内插件并更新本机安装，桌面软件不变。不要把测试容器截图或CLI安装成功描述为公共市场已上架。

## 官方安装目标

获准提交并审核发布后，用户在 GPT 插件目录选择本插件、检查权限并安装，由宿主启动包内本地 MCP；无需软件安装器、Node 配置或 7449 控制面板。当前尚未取得上架资格，GitHub ZIP 是待审核构建产物，不是官方商店安装入口。不能用安装独立软件代替此流程。

## 0.2.1 加载修复

当前客户端的可移植stdio解析器拒绝server.extensions及command中的PLUGIN_ROOT；command改为包内 ./runtime/node.exe，运行参数和cwd仍按宿主支持的PLUGIN_ROOT解析。已用真实Codex插件加载器发现petapp服务和global/thread入口。

启用开关负责允许加载；打开侧栏“额度伙伴”入口后直接显示人物，所有设置仍在人物右键菜单。插件不接管桌面软件。
## 0.2.2 音效与显示范围

音效改用单个 Web Audio 上下文：用户点击时恢复播放、按需解码并缓存包内原版音效，不依赖 media URL。播放失败会在右键菜单提示，隐藏后取消待播放音效。

右键菜单增加“悬浮显示（画中画）”，宿主提供接口时才显示。请求被拒绝或降级时明确提示；不伪装成已进入悬浮模式。当前客户端真实画中画能力仍由宿主决定，SDK测试容器只能验证协议请求和菜单状态。

官方画中画属于GPT会话内的悬浮展示，不等于覆盖所有聊天、所有窗口或Windows桌面。插件启用开关也不提供自动创建系统浮窗的契约。需要系统桌面常驻时使用独立桌面版，两版保持独立。
